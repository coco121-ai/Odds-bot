# ⚽ Odds Bot

Παρακολουθεί πτώσεις αποδόσεων στα «έξυπνα λεφτά» (Pinnacle, Betfair Exchange) και σε ειδοποιεί
στο Telegram, ειδικά όταν ένας ελληνικός bookmaker (Stoiximan, Pamestoixima) δεν έχει προλάβει να
ρίξει την απόδοση. Τρέχει δωρεάν στο GitHub, κάθε 10 λεπτά, χωρίς τον υπολογιστή σου.

## Τι ειδοποιήσεις στέλνει

**Αγορές:** Τελικό 1Χ2 · Over/Under 2.5 · Over/Under ημιχρόνου (0.5 και 1.5) · Ακριβές σκορ
**Πότε:** προαγωνιστικά (από 6 ώρες πριν) **και** live.
**Ήσυχες ώρες 02:00–11:00:** μόνο σοβαρές περιπτώσεις (🔥, πτώση ≥ 25% ή αξία ≥ 10%), με την ένδειξη 🚨. Τα υπόλοιπα, αν ισχύουν ακόμα, έρχονται μετά τις 11:00.

| Σήμα | Πότε |
|---|---|
| 📉 **ΠΤΩΣΗ ΑΠΟΔΟΣΗΣ** | Pinnacle ή Betfair έπεσε ≥ 12% την τελευταία ώρα ή ≥ 20% από την αρχή (μόνο προαγωνιστικά) |
| 💰 **ΕΥΚΑΙΡΙΑ ΑΞΙΑΣ** | Ελληνικός bookmaker δίνει ≥ 5% πάνω από τη «δίκαιη» απόδοση (≥ 7% στα live) |
| 🔥 **ΠΤΩΣΗ + ΑΞΙΑ** | Και τα δύο μαζί, το πιο δυνατό σήμα |

Όλα τα όρια αλλάζουν στο `config.py`.

## Εγκατάσταση (περίπου 15 λεπτά, μία φορά)

### 1. Κλειδί OddsPapi (δωρεάν)
1. Κάνε εγγραφή στο https://oddspapi.io/us/sign-up
2. Από τη σελίδα **Account** αντέγραψε το **API key**.

### 2. Telegram bot
1. Στο Telegram άνοιξε το **@BotFather** → γράψε `/newbot` → δώσε όνομα.
2. Θα σου δώσει ένα **token** (μοιάζει με `123456:ABC-xyz...`). Κράτα το.
3. Άνοιξε το bot που έφτιαξες και στείλε του ένα οποιοδήποτε μήνυμα (π.χ. «γεια»).
4. Άνοιξε στον browser τη διεύθυνση (βάλε το δικό σου token):
   `https://api.telegram.org/bot<TOKEN>/getUpdates`
   Ψάξε το `"chat":{"id":123456789` — αυτός ο αριθμός είναι το **chat id**.

### 3. GitHub
1. Φτιάξε δωρεάν λογαριασμό στο https://github.com
2. Πάτα **New repository** → όνομα π.χ. `odds-bot` → επίλεξε **Public** → **Create**.
   > Δημόσιο γιατί έτσι το GitHub Actions είναι απεριόριστα δωρεάν. Τα κλειδιά σου **δεν** φαίνονται
   > (μπαίνουν κρυφά στο βήμα 4). Φαίνεται μόνο ο κώδικας.
3. Πάτα **uploading an existing file** και σύρε μέσα **όλα** τα αρχεία του φακέλου,
   **μαζί με τον φάκελο `.github`** → **Commit changes**.
   > Αν ο φάκελος `.github` δεν ανέβει (είναι κρυφός σε Mac/Windows): **Add file → Create new file**,
   > γράψε όνομα `.github/workflows/bot.yml` και κάνε επικόλληση το περιεχόμενο του αρχείου.

### 4. Βάλε τα κλειδιά (Secrets)
**Settings → Secrets and variables → Actions → New repository secret**, τρεις φορές:

| Name | Value |
|---|---|
| `ODDSPAPI_KEY` | το κλειδί του OddsPapi |
| `TELEGRAM_TOKEN` | το token του BotFather |
| `TELEGRAM_CHAT_ID` | το chat id |

### 5. Δοκιμή
1. Καρτέλα **Actions** → αν ζητήσει, πάτα **I understand… enable them**.
2. Αριστερά **Odds Bot** → **Run workflow** → mode: **test-telegram** → **Run**.
   Σε ~30 δευτερόλεπτα πρέπει να έρθει μήνυμα στο Telegram ✅
3. Ξανά **Run workflow** με mode **run** για έναν πραγματικό γύρο.

Από εδώ και πέρα τρέχει μόνο του κάθε 10 λεπτά.

## Καλό να ξέρεις

- **Όριο δωρεάν πλάνου:** 250 αιτήματα/μήνα. Το bot ξοδεύει ~4 τη μέρα (≈120/μήνα) μόνο για τη λίστα
  αγώνων. Το ιστορικό αποδόσεων, που κάνει όλη τη δουλειά, **δεν χρεώνεται**.
  Έλεγχος: **Run workflow → quota**.
- **Καθυστέρηση:** το GitHub δεν ξεκινάει πάντα στο λεπτό· μπορεί να αργήσει 5–15′ σε ώρες αιχμής.
- **Λίγκες:** 1η, 2η και 3η κατηγορία σε 26 χώρες (Αγγλία, Ισπανία, Ιταλία, Γερμανία, Γαλλία, Ελλάδα,
  Ολλανδία, Πορτογαλία, Τουρκία, Βέλγιο, Σκωτία, Ελβετία, Δανία, Αυστρία, Νορβηγία, Σουηδία, Πολωνία,
  Τσεχία, Κροατία, Ρουμανία, Σερβία, Κύπρος, Σαουδική Αραβία, ΗΠΑ, Βραζιλία, Αργεντινή) + Champions,
  Europa, Conference League. Μόνο αγώνες που έχουν αποδόσεις **και** στο Pinnacle **και** στους δύο
  ελληνικούς bookmakers. Για να δεις ποιες λίγκες πιάνει: **Run workflow → leagues** (✅ = παρακολουθείται).
- **Κάθε γύρος** ελέγχει έως 60 αγώνες που ξεκινούν τις επόμενες 6 ώρες. Πρώτα τα live, μετά όσοι ξεκινούν μέσα σε 2 ώρες
  ελέγχονται κάθε φορά· οι υπόλοιποι εκ περιτροπής.
- **Άλλοι bookmakers:** στο `config.py`, `GREEK_BOOKS` (μέχρι 2): `stoiximan`, `pamestoixima-gr`,
  `bet365-gr`, `vistabet`, `interwetten`, `bwin`, `netbet`. Η Novibet δεν καλύπτεται από το OddsPapi.
- **Αν σταματήσει:** το GitHub απενεργοποιεί προγράμματα μετά από 60 μέρες χωρίς δραστηριότητα· το bot
  γράφει μόνο του στο repository, οπότε κανονικά δεν συμβαίνει. Αν συμβεί, Actions → **Enable workflow**.
- **Live:** στα live οι αποδόσεις πέφτουν φυσιολογικά με τον χρόνο και τα γκολ, οπότε το bot στέλνει
  μόνο ευκαιρίες αξίας, και μόνο με τιμές που ανανεώθηκαν τα τελευταία 5 λεπτά. Κάθε live αγώνας
  ελέγχεται μία φορά ανά γύρο (κάθε ~10′), άρα στα live πρέπει να κινηθείς γρήγορα.
- **Αγορές:** το bot βρίσκει μόνο του τους κωδικούς τους. Για έλεγχο: **Run workflow → markets**.
- **Τεστ λογικής** στον υπολογιστή σου: `python test_bot.py`

⚠️ Οι ειδοποιήσεις είναι σήματα, όχι εγγυημένα κέρδη. Παίζε υπεύθυνα.
